# Umbrly Language Support (VS Code)

Расширение VS Code для языка [Umbrly](../README.md): подсветка синтаксиса, автодополнение,
подсказки при наведении и подсказки параметров по всем 102 встроенным функциям, сниппеты и
иконка файла (зонтик) для `.umb`.

## Что даёт

- **Подсветка синтаксиса** — ключевые слова (`PRINT`, `IF`, `FUNC`, ...), типизированные
  переменные (`INT_x`, `STR_y`, ...) с отдельным цветом для префикса типа, встроенные функции
  отдельным цветом от пользовательских, интерполяция `[выражение]` внутри строк подсвечивается
  как код, а не как обычный текст.
- **Автодополнение** — все ключевые слова и 102 встроенные функции по `Ctrl+Space`.
- **Hover** — наведите курсор на любое ключевое слово или функцию, увидите сигнатуру и описание.
- **Подсказка параметров** — при наборе `SUBSTR(` показывает `SUBSTR(s, start, len)` и
  подсвечивает текущий параметр по мере ввода запятых — как для встроенных функций Python.
- **Сниппеты** — `if`, `ifelse`, `while`, `for`, `forstep`, `func`, `try`, `print`, `input` +
  Tab для быстрого набора скелетов конструкций.
- **Иконка файла** — `.umb` показывается с иконкой зонтика в вкладках, хлебных крошках и (если
  активная тема иконок не задаёт своей иконки для незнакомых расширений — это касается почти
  всех тем) в проводнике файлов.
- **Кнопка запуска** — как «Run Python File»: кнопка ▶ в правом верхнем углу редактора (или
  `Ctrl+F5`) сохраняет файл и запускает его через интерпретатор в интегрированном терминале
  внизу — с полноценным вводом-выводом (`INPUT:`, `GETKEY`, цвет консоли и т.д.).
- **Настройка пути к интерпретатору** — `File → Preferences → Settings` → искать `Umbrly`,
  или прямо в `settings.json`:
  ```json
  "umbrly.interpreterPath": "C:\\projects\\umbrly\\umbrly.exe"
  ```
  Можно указать имя команды (если `umbrly.exe` есть в PATH — тогда можно оставить значение
  по умолчанию), путь относительно корня открытой папки (например `umbrly.exe`, если `.vscode`
  открыт в корне проекта интерпретатора), либо полный абсолютный путь.

## Установка (без публикации в Marketplace)

Расширение не опубликовано в Marketplace — установите локально одним из двух способов.

### Способ 1 — скопировать в папку расширений (проще всего)

```powershell
Copy-Item -Recurse "vscode-umbrly" "$env:USERPROFILE\.vscode\extensions\umbrly-language-0.1.0"
```

Затем перезапустите VS Code (или `Ctrl+Shift+P` → `Developer: Reload Window`).

### Способ 2 — упаковать в .vsix и установить через интерфейс

Нужен `vsce` (ставится один раз глобально):

```powershell
npm install -g @vscode/vsce
cd vscode-umbrly
vsce package
```

Появится файл `umbrly-language-0.1.0.vsix`. В VS Code: `Ctrl+Shift+P` →
`Extensions: Install from VSIX...` → выбрать этот файл.

## Проверка

Откройте любой файл из `../examples/*.umb` — должна появиться подсветка, иконка зонтика на
вкладке, а наведение на `PRINT`, `FOR`, `SUBSTR` и т.п. должно показывать всплывающую подсказку.

## Структура

```
package.json                  манифест расширения (языки, грамматика, сниппеты, иконка)
language-configuration.json   комментарии, скобки, автоотступы
syntaxes/umbrly.tmLanguage.json   грамматика TextMate для подсветки
icons/umbrella-{light,dark}.svg   иконка файла .umb
snippets/umbrly.code-snippets     сниппеты
src/builtins-data.js             данные: сигнатуры и описания всех ключевых слов и функций
src/extension.js                  автодополнение, hover, signature help
```

Список функций в `src/builtins-data.js` — ручная копия из [README.md](../README.md) языка.
При добавлении новых встроенных функций в `src/builtins.cpp` / `src/winapi_bindings.cpp`
не забудьте обновить и этот файл.
