          Umbrly — интерпретируемый язык для Windows. Тип переменной — это её имя
          (INT_, STR_, ARR_…), команды заканчиваются
          двоеточием, а треть из 71 встроенной функции — прямые обёртки над WinAPI.
        

        

          
          
        

        
Один .exe. Ноль внешних зависимостей. Модульная сборка: лексер → парсер → AST → интерпретатор.

      

    

  


  

    
01 Синтаксис за минуту

    

      
FUNC IS_EVEN(INT_N):
    RETURN INT_N % 2 == 0
END

INT_X = INPUT: "Введите число: "
IF: IS_EVEN(INT_X)
    PRINT: "[INT_X] — чётное"
ELSE:
    PRINT: "[INT_X] — нечётное"
END


      
    
        
  • 
          
          FUNC / IF / ELSE / END — границы структуры. Отступы — для человека, не для интерпретатора: закрывает блок именно ключевое слово END.
        
    • 
        
  • 
          
          PRINT: / INPUT: — команды ввода-вывода. После двоеточия — аргумент: строка, выражение или ничего.
        
    • 
        
  • 
          
          INT_N, INT_X — тип переменной прямо в имени. Отдельного объявления типа не существует в принципе.
        
    • 
        
  • 
          
          [INT_X] — подстановка внутри строки. Внутри скобок — полноценное выражение, вычисляется в момент вывода.
        
    • 
      

    

  


  

    
02 Конструкции языка

    


      

        
Условие

        
IF: INT_X > 10
    PRINT: "большое"
ELSE:
    PRINT: "маленькое"
END

        
ELSE необязателен, блоки вкладываются друг в друга.

      


      

        
Цикл WHILE

        
WHILE: INT_I < 5
    PRINT: "[INT_I]"
    INT_I = INT_I + 1
END

        
BREAK и CONTINUE работают как в любом C-подобном языке.

      


      

        
Цикл FOR

        
FOR: INT_I = 10 TO 1 STEP -1
    PRINT: "[INT_I]"
END

        
Границы включительны, TO обязателен, STEP — нет (по умолчанию 1).

      


      

        
Массивы

        
ARR_XS = [10, 20, 30]
PUSH(ARR_XS, 40)
PRINT: "[ARR_XS[0]] / [LEN(ARR_XS)]"

        
Индексация с нуля; присваивание по индексу — ARR_XS[i] = ...

      


      

        
Функции

        
FUNC FACT(INT_N):
    IF: INT_N <= 1
        RETURN 1
    END
    RETURN INT_N * FACT(INT_N - 1)
END

        
Рекурсия работает; функции регистрируются заранее — вызов «вперёд» по коду допустим.

      


      

        
Ошибки

        
TRY:
    INT_X = TOINT("не число")
CATCH: STR_ERR
    PRINT: "Поймали: [STR_ERR]"
END

        
Ошибка не роняет программу, если её явно ждут.

04 Не игрушка: PATH Doctor

    

      

        

          path_doctor.umb — рабочий скрипт на Umbrly, не демо. Он читает переменную
          окружения PATH, разбивает её на записи и для каждой проверяет, существует
          ли папка ещё на диске. Программы удаляют, переустанавливают, путь захламляется —
          а Windows перебирает все эти записи по порядку при запуске любой команды.
        

        

          Скрипт ничего не удаляет и не правит: только показывает битые пути и дубликаты,
          красит вывод через COLOR() и сохраняет отчёт файлом через
          FILE_WRITE(). Реальный прогон на рабочей машине:
        

      

      
[OK]        C:\Windows\System32
[НЕ НАЙДЕН] C:\Users\dev\bin
[ДУБЛИКАТ]  C:\Program Files\Git\mingw64\bin
[OK]        C:\Program Files\nodejs
[НЕ НАЙДЕН] C:\Users\dev\.dotnet\tools
[OK]        C:\Users\dev\.cargo\bin

Итого: 42 записей -- рабочих: 27, битых: 8, дублей: 7, пустых: 0
